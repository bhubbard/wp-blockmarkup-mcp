wp-blockmarkup-mcp — Rust Gutenberg Block Markup Parser, Validator & MCP Server

wp-blockmarkup-mcp is a zero-copy Rust parser, linter, and Model Context Protocol (MCP) server that eliminates ”Attempt Block Recovery” errors when AI agents generate WordPress Gutenberg blocks. It validates HTML comment attribute JSON against innerHTML markup and auto-heals serialization mismatches in microseconds.
